Both apps can be installed on the same Android device. VProtect uses `com.neurovprotect.vprotect`; Vyora uses `com.neurovprotect.vyora`. These are standalone release builds and do not require a development server.

Requirements: Android 7.0 or newer, ARM64 or ARMv7 device. Download the APK on your phone and allow installation from your browser when Android asks. Keep the installed app to retain its local data when installing later updates of the same brand.

This repository distributes APKs only. Application source is maintained privately. Each release includes a SHA-256 checksum file for download verification.
